# Changesets

Never by hand: use `bun --bun changeset` or `bun run changeset:conventional`.

Write in English, at most 3 lines. Briefly: what and why changed, not which files moved.

Name workspace packages and apps only. Never `spotter`: the root is not a workspace member — fails the release.
