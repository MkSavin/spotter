# Конфигурация: неочевидное

## Комментарий `# hint` из примера может стать значением

`--env-file` в Bun и `env_file` в compose обрезают хвостовой `# подсказка`. Но значение, попавшее другим путём — через `environment:` в compose, `export` в шелле, переменную CI, — передаётся дословно, и подсказка молча становится частью значения.

Поэтому хвост срезается только у ограниченных значений (enum, число, булево, список) и никогда у свободных: секрет или URL вполне может содержать `#`.
