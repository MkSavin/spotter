# Свой Bot API-сервер: видео целиком

Обычный Bot API берёт у бота файл не больше 50 МБ. Длинное событие в такой лимит не влезает и приходит в чат частями: одно видео в сообщении и ещё несколько ответами под ним. Свой Bot API-сервер поднимает лимит до 2 ГБ, и то же событие приходит одним видео.

Это необязательная надстройка. Без неё всё работает, просто длинные клипы режутся. Решает та же пара ключей, что и у любого приложения для Telegram, и один контейнер рядом с ботом.

## Как это устроено

Рядом с `spotter-telegram` поднимается контейнер `telegram-bot-api` (официальный сервер Bot API от Telegram, образ `aiogram/telegram-bot-api`). Бот ходит в него по внутренней сети Docker, а он сам говорит с дата-центрами Telegram по MTProto. Бот с ним общается тем же протоколом, что и с облаком, поэтому в самом боте ничего не меняется, кроме адреса сервера и лимита.

Два следствия, о которых стоит знать заранее:

- Бот числится ровно на одном сервере. Перед переездом на свой он выходит из облачного, и обратно Telegram пускает его только через 10 минут. Этот выход делает `./spotter` сам при первом подъёме с флагом.
- Режет клипы на части депо, а не бот. На одной машине лимит резки переключит мастер; в распределённом деплое его надо поднять на ingest-узле руками (ниже).

## Что нужно

- `api_id` и `api_hash`. Выдаются на [my.telegram.org](https://my.telegram.org) в разделе «API development tools»: войди под своим номером, создай приложение с любым названием, скопируй оба значения. Это ключи приложения, не аккаунта, но держи их как токен бота.
- Место на диске. Бот скачивает клип во временный файл, а сервер хранит у себя копию того, что переслал: на клип в полтора гигабайта нужно столько же свободного места дважды.

## Включить при установке

Мастер спрашивает об этом сам, после PWA:

```
[7] Большие видео (опционально)
  Поднять свой Bot API-сервер? (y/N): y
  TELEGRAM_API_ID: 12345678
  TELEGRAM_API_HASH: 0123456789abcdef0123456789abcdef
```

Дальше он всё сделает сам: запишет ключи в `.env`, на одной машине поставит `VIDEO_PART_LIMIT_MB=2000`, а при подъёме выведет бота из облака и запустит контейнер.

## Включить на работающем узле

В `.env` на машине с ботом (single или cloud):

```
TELEGRAM_API_ID=12345678
TELEGRAM_API_HASH=0123456789abcdef0123456789abcdef
```

На машине, где работает депо (та же single или ingest):

```
VIDEO_PART_LIMIT_MB=2000
```

И поднять с флагом, один раз:

```bash
./spotter up --botapi
```

Флаг запоминается в `SPOTTER_PROFILES`, так что `./spotter update` и обычный `./spotter up` дальше держат сервер сами. На ingest после правки `.env` нужен `./spotter recreate depot`.

Проверить, что бот переехал:

```bash
./spotter logs telegram | grep 'Bot API redirected'
./spotter doctor
```

Первая команда печатает `Bot API redirected to http://telegram-bot-api:8081`, вторая считает контейнер `telegram-bot-api` обязательным и скажет, если его нет.

## Если Telegram недоступен напрямую

Сервер Bot API умеет ходить через прокси. В `.env`:

```
TELEGRAM_PROXY=socks5://user:password@host:1080
```

и `./spotter recreate telegram-bot-api`. Пустое значение означает прямое соединение.

## Вернуться в облако

Убери `botapi` из `SPOTTER_PROFILES` в `.env`, верни `VIDEO_PART_LIMIT_MB=50` там, где работает депо, и подними заново:

```bash
./spotter up
```

Бот снова пойдёт в `api.telegram.org`. Telegram примет его не раньше чем через 10 минут после выхода, поэтому первые минуты в логах может быть `401`.

## Что-то пошло не так

| Симптом | Причина |
| --- | --- |
| `401 Unauthorized` от своего сервера, бот молчит | бот ещё числится в облаке. `./spotter botapi-logout` повторит выход; если `api.telegram.org` с этой машины недоступен, выполни `curl -X POST https://api.telegram.org/bot<TELEGRAM_TOKEN>/logOut` откуда угодно |
| `в .env нет TELEGRAM_API_ID` | ключи не записаны, см. «Что нужно» |
| Контейнер `telegram-bot-api` падает сразу | неверные `api_id`/`api_hash`: `./spotter logs telegram-bot-api` |
| Видео всё ещё приходит частями | депо режет по старому лимиту: `VIDEO_PART_LIMIT_MB=2000` на машине с депо и `./spotter recreate depot` |
| «Видео не влезает в Telegram» в подписи | клип больше лимита загрузки у текущего сервера; с кнопкой «Смотреть в приложении», если поднято PWA |
