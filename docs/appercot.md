# Фронтенд Appercot

Appercot принимает уведомления Spotter в личных чатах бота. Фронтенд использует тот же сервер авторизации, каталог камер и медиаконвейер, что и Telegram. Запускать оба бота можно одновременно. У каждого своя привязка аккаунтов, поэтому для входа в Appercot понадобится новый одноразовый код.

## Запуск

1. Создайте отдельного бота в Appercot и получите его токен. Для бота с доступом по приглашению подготовьте ссылку средствами Appercot.
2. Добавьте настройки в `.env` узла `single` или `cloud`.

   ```dotenv
   APPERCOT_TOKEN=<токен бота>
   APPERCOT_WS_URL=wss://appercot.example.com/api/bot/ws
   ```

   Сервис использует общие настройки `REDIS_*`, `S3_*` и `TZ`. Если адрес `S3_HOST` доступен только внутри сети Spotter, укажите `APPERCOT_S3_PUBLIC_URL` с адресом S3, доступным пользователям. Подписанные ссылки используют этот адрес и срок `S3_PRESIGN_EXPIRY`. Appercot-фронтенд загружает снимки через `S3_HOST`.

3. Запустите `./spotter up --appercot`. Флаг сохраняет профиль для `./spotter update`. Compose использует образ `ghcr.io/mksavin/spotter-appercot:latest`. Для конкретной опубликованной версии задайте `APPERCOT_IMAGE`. База хранится в `.docker/appercot/`. Состояние видно в `./spotter doctor`, логи доступны через `./spotter logs appercot`.
4. Создайте первый код командой `./spotter token admin`. Откройте чат своего бота в Appercot и отправьте `/start <код>`. Для приглашения остальных используйте `/user_sign [@username] [роль]` и передайте команду `/start <код>` вместе со ссылкой на чат. Именной код действует в платформе, где его выдали.

Для локальной разработки запускайте `bun --filter @spotter/appercot start` из корня репозитория. В `.env` укажите адреса Redis, S3 и Appercot, доступные с машины разработчика.

## Работа в чате

- Снимок появляется в исходном сообщении о событии. Если его не удалось прикрепить, кнопка «Снимок» выдаёт свежую ссылку.
- «Видео» запускает подготовку клипа. После завершения кнопка выдаёт временную ссылку на готовый файл. Таймлапсы также приходят ссылками.
- `/camera_list` показывает коды камер. Например, `/camera_snapshot driveway`, `/timelapse driveway сегодня` и `/mute 2ч` выполняются прямо из чата. Команда без обязательных аргументов показывает подсказку по синтаксису.
- `/user_list` показывает UUID для `/user_promote`, `/user_demote` и `/user_revoke`. Права `VIEWER`, `USER` и `ADMIN` определяет сервер Spotter, включая доступ для владельца бота в Appercot.
